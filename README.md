## Built-in objects and methods used
- `Date()` — creates the current date object
- `getMonth()`, `getDate()`, `getFullYear()` — retrieve date parts
- `String()` and `padStart()` — add leading zeroes to month and day
- `Number()` — converts string values into numbers
- `Number.isNaN()` — checks whether a value is NaN
- `Number.isInteger()` — checks whether a value is an integer
- `toFixed(2)` — formats the grade average to two decimal places
- `toLocaleString()` — formats the total score
- `document.getElementById()` and `innerHTML` — display results on the webpage
